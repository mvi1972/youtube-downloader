# 🌐 Эмуляторы браузера для обхода защиты YouTube

Этот проект содержит два эмулятора браузера для обхода защиты YouTube и скачивания видео.

## 🎯 Принцип работы

Эмуляторы работают по принципу **"эмуляции реального пользователя"**:

1. **Запускают реальный браузер** (Chrome/Chromium)
2. **Эмулируют человеческое поведение** (движения мыши, скроллы, клики)
3. **Обходят детекцию ботов** через настройки браузера
4. **Извлекают видео потоки** из сетевых запросов
5. **Скачивают видео** без отображения на экране

## 🚀 Доступные эмуляторы

### 1. **Playwright Emulator** (`browser_emulator.py`)

- **Преимущества**: Современный, быстрый, лучше обходит детекцию
- **Недостатки**: Сложнее в настройке, требует установки браузеров
- **Использование**: Для продвинутых пользователей

### 2. **Selenium Emulator** (`selenium_emulator.py`)

- **Преимущества**: Простой, стабильный, широко поддерживается
- **Недостатки**: Медленнее, хуже обходит детекцию
- **Использование**: Для начинающих пользователей

## 📦 Установка зависимостей

### Для Playwright:

```bash
pip install playwright
playwright install chromium
```

### Для Selenium:

```bash
pip install selenium webdriver-manager
```

## 🔧 Настройка

### 1. **Cookies**

Эмуляторы используют cookies из Firefox для авторизации:

```bash
# Получение cookies из Firefox
python -m yt_dlp --cookies-from-browser firefox --cookies cookies_firefox.txt https://youtube.com
```

### 2. **Конфигурация**

В коде эмулятора настройте:

- `headless`: `True` для фонового режима, `False` для видимого
- `cookies_path`: путь к файлу cookies
- `download_path`: папка для сохранения видео

## 🔍 Как это работает

### 1. **Запуск браузера**

- Эмулятор запускает Chrome/Chromium с настройками для обхода детекции
- Отключает функции, которые могут выдать автоматизацию
- Устанавливает человеческий User-Agent

### 2. **Загрузка cookies**

- Загружает cookies из файла для авторизации
- Эмулирует вход в аккаунт YouTube

### 3. **Переход к видео**

- Переходит на страницу видео
- Ждет загрузки плеера и контента

### 4. **Эмуляция поведения**

- Нажимает кнопку Play
- Эмулирует движения мыши
- Выполняет случайные скроллы
- Имитирует человеческое взаимодействие

### 5. **Извлечение видео**

- Перехватывает сетевые запросы
- Фильтрует URL видео потоков
- Извлекает прямые ссылки на видео

### 6. **Скачивание**

- Скачивает видео потоки
- Сохраняет на диск
- Закрывает браузер

## 🚨 Устранение проблем

### 1. **Ошибка "Chrome не найден"**

```bash
# Установите Chrome или используйте webdriver-manager
pip install webdriver-manager
```

### 2. **Ошибка "Cookies не работают"**

```bash
# Обновите cookies
python -m yt_dlp --cookies-from-browser firefox --cookies cookies_new.txt https://youtube.com
```

### 3. **Ошибка "Видео заблокировано"**

- Попробуйте другой URL
- Обновите cookies
- Измените User-Agent
- Увеличьте задержки

### 4. **Медленная работа**

- Отключите загрузку изображений
- Уменьшите время эмуляции
- Используйте headless режим
