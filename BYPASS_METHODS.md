# Продвинутые методы обхода защиты YouTube

## 🛡️ Обзор методов обхода
Приложение использует несколько методов для обхода защиты YouTube:
1. Ротация User-Agent
2. Использование прокси и VPN
3. Smart DNS
4. Ротация IP через Tor
5. Эмуляция мобильных устройств
6. Автоматическое переключение методов при обнаружении блокировки

## 🔧 Детали методов

### Ротация User-Agent
- При каждом запросе отправляется случайный User-Agent
- Список включает последние версии популярных браузеров
- Помогает избежать блокировки по fingerprint браузера

### Прокси и VPN
- Использование публичных прокси из автоматически обновляемого списка
- Поддержка HTTP, HTTPS и SOCKS5 прокси
- Ручное указание прокси во вкладке настроек

### Smart DNS
- Обход географических ограничений без изменения IP
- Уменьшает задержки по сравнению с VPN
- Включается в настройках вкладки "Обход защиты"

### Tor
- Полная анонимизация трафика
- Ротация IP каждые 10 минут
- Требует установленного и запущенного Tor браузера

### Эмуляция мобильных устройств
- Использование мобильных User-Agent
- Эмуляция запросов с Android и iOS устройств
- Автоматическое переключение при ошибках доступа

## ⚙️ Настройка методов
1. Перейдите во вкладку "Обход защиты"
2. Выберите нужные методы:
   - Smart DNS
   - Tor
   - Ротация User-Agent
3. Для Tor убедитесь что браузер запущен
4. Для прокси укажите адрес в поле "Прокси"

## 💡 Рекомендации
1. Для максимальной анонимности используйте Tor + ротацию User-Agent
2. Для высокой скорости используйте Smart DNS
3. При частых ошибках 429 включайте ротацию прокси
4. Для возрастных видео используйте cookies + мобильную эмуляцию

## 🛠️ Устранение проблем
### "Обнаружена защита от ботов"
1. Включите ротацию User-Agent
2. Добавьте свежие cookies
3. Используйте Tor или смените прокси

### "Видео недоступно в вашем регионе"
1. Включите Smart DNS
2. Используйте VPN/прокси другого региона
3. Попробуйте мобильный метод обхода

### "Слишком много запросов"
1. Увеличьте интервал между запросами
2. Используйте ротацию прокси
3. Включите Smart DNS для уменьшения видимости запросов

## 📞 Поддержка
При возникновении проблем:
1. Проверьте логи во вкладке "Загрузка"
2. Попробуйте комбинации разных методов
3. Обновите приложение до последней версии
4. Обратитесь в поддержку с подробным описанием проблемы
