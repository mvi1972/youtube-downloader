# 🎬 YouTube Downloader

Продвинутое приложение для скачивания видео с YouTube с поддержкой множественных загрузок, обхода блокировок и интеллектуальной обработки ошибок.

## ✨ Особенности

- 🚀 **Множественные загрузки** - система очередей для одновременного скачивания
- 🔐 **Автоматическое получение cookies** - безопасная авторизация
- 🛡️ **Обход блокировок** - Smart DNS, Tor, прокси, мобильная эмуляция
- 📱 **Кроссплатформенность** - Windows, macOS, Linux
- 🎨 **Современный GUI** - PySide6/PyQt6 интерфейс
- ⚡ **Интеллектуальная обработка ошибок** - региональные ограничения, авторские права
- 🔒 **Анонимный режим** - работа без cookies

## 📋 Требования

- Python 3.8+
- PySide6 или PyQt6
- yt-dlp
- requests
- beautifulsoup4

## 🚀 Быстрая установка


## 🎯 Использование

### Базовое использование
1. Запустите приложение: `python app.py`
2. Вставьте URL видео
3. Выберите качество
4. Нажмите "Скачать"

### Расширенные настройки
- Используйте cookies для обхода блокировок
- Настройте прокси в настройках
- Используйте систему очередей для множественных загрузок

## 🐛 Решение проблем

### Ошибка "Sign in to confirm you're not a bot"
1. Получите cookies через браузер
2. Сохраните в `~/.youtube_downloader/cookies/`
3. Перезапустите приложение

### Ошибки кодировки в Windows
- Убедитесь, что используете Python 3.8+
- Проверьте настройки локали
