# Руководство по работе с очередью скачивания

## 🚀 Основные возможности
- Добавление нескольких URL для последовательного скачивания
- Автоматическое скачивание по очереди
- Управление очередью (пауза, возобновление, очистка)
- Просмотр прогресса скачивания каждого видео

## 📋 Как использовать

### Добавление видео в очередь
1. Перейдите на вкладку "Очередь"
2. Введите URL видео в поле ввода
3. Нажмите кнопку "Добавить"
4. Видео появится в таблице очереди со статусом "Ожидание"

### Управление очередью
- **Старт**: Нажмите "Старт" для начала скачивания всей очереди
- **Пауза**: Нажмите "Пауза" для временной остановки скачивания
- **Удаление**: Нажмите "Удалить" рядом с видео для его удаления из очереди
- **Очистка**: Нажмите "Очистить" для полной очистки очереди

### Статусы скачивания
- **Ожидание**: Видео ждет своей очереди
- **В процессе**: Видео скачивается в данный момент
- **Завершено**: Видео успешно скачено

## ⚙️ Настройки очереди
- **Автостарт**: Очередь автоматически запускается при добавлении первого видео
- **Лимит очереди**: Максимум 50 видео в очереди (для предотвращения перегрузки)
- **Повтор при ошибке**: При ошибке скачивания видео автоматически повторяется 3 раза

## 💡 Советы
1. Вы можете добавлять видео во время скачивания очереди
2. При перезапуске приложения очередь сохраняется автоматически
3. Для скачивания плейлистов используйте специальный режим (в разработке)

## 🛠️ Устранение проблем
### Очередь не запускается
- Проверьте подключение к интернету
- Убедитесь, что в очереди есть видео
- Проверьте настройки прокси и cookies

### Видео зависло в статусе "В процессе"
- Нажмите "Пауза", затем "Старт" для перезапуска
- Проверьте URL видео на доступность
- Убедитесь, что файл не скачивается в данный момент

## 📞 Поддержка
При возникновении проблем:
1. Проверьте логи во вкладке "Загрузка"
2. Попробуйте перезапустить приложение
3. Обратитесь в службу поддержки с копией логов
